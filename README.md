# 🚀 RPG2JAVA - AI-Powered IBM i Modernization Assistant

An AI-powered assistant for IBM i (RPG ILE, CL, DDS) modernization to Java 21 (Clean Architecture).

## 🛠️ Tech Stack
- **LLM:** Qwen 2.5 1.5B (Unsloth)
- **Fine-Tuning:** QLoRA (4-bit)
- **RAG:** ChromaDB + Sentence Transformers
- **Embeddings:** all-MiniLM-L6-v2
- **Environment:** Google Colab (T4 GPU)
- **Languages:** Python, RPG ILE, CL, Java 21

## 📊 Dataset
- **Total:** 111 Q&A pairs
- **Topics:** CHAIN, UNLOCK, DATA-GEN, Subfiles, Service Programs, CL calls, IBM i 7.5, Java migration
- **Format:** JSONL (ChatML)
